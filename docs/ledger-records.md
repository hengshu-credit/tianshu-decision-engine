# 台账记录

控制台的「台账记录」包含时间线、文章管理和素材库。页面复用现有项目选择、Element Plus 筛选工具栏、主题令牌与 `ResourceVersionManager` 版本管理组件。

## 文章和版本

- 新建文章或修改已发布文章时，先保存作者私有草稿。未发布内容不会进入团队时间线，也不会覆盖当前已发布版本。
- 发布后形成不可变的 v1、v2 等版本。初次发布按填写的发生时间排列，后续变更按实际发布时间进入时间线，卡片同时保留原发生时间。
- 文章管理集中展示本人草稿和有权查看的已发布文章。版本管理可预览各版本、比较正文及配置信息，也可基于历史版本生成草稿；恢复不会直接切换发布版本。
- 全量时间线使用连续轴和两行卡片，悬停预览详情；选择事件后展示详情卡片。事件可多选，按并集筛选，同一发布版本只出现一次。
- 日期范围精确到秒，提供常用快捷区间；日期上的新增/变更标记和悬停标题使用与时间线相同的权限及筛选条件。
- 文章、事件、素材通过数据库 ID 关联。更名不会破坏关联；发布后正文和关联快照不被后续草稿覆盖。
- 未填写摘要时，每个发布版本从当次正文重新提取摘要；手工摘要会保留，清空后恢复自动生成。

## 权限

`ledger:view` 控制模块查看，`ledger:edit` 控制编写和上传，`ledger:manage` 允许维护获授权范围内他人的已发布内容与素材。管理权限仍与项目范围、全局只读限制相交，不授予私有草稿读取能力。

私有草稿和私有素材按稳定账户 ID 隔离。已发布文章及版本按模块、当前文章归属和版本归属共同授权；调整范围不会使原来受限的历史正文自动变得可见。事件选项、日历计数、版本对比、素材引用和图片内容接口均执行服务端授权。

素材引用不能用于扩大权限。项目素材不能发布到其他项目或全局文章。本人未共享的可用素材在首次文章发布时按文章范围共享；存在其他草稿引用时须先由上传者在素材库明确共享范围。已共享且存在引用的素材不可改范围；任何被引用的素材均不可删除，重命名不改变 ID。

## 上传与病毒检测

上传仅接受 5 MB 以内、文件签名与扩展名一致的 PNG、JPEG、WebP。先存入数据库私有暂存区，使用 ClamD `INSTREAM` 扫描原始字节，只有完整的 `stream: OK` 响应才继续处理。随后检查图片尺寸（每边不超过 4096、总像素不超过 1600 万）并重编码为 PNG，去除原始附加数据与元信息；原始文件不通过静态目录提供。

扫描未配置、超时或响应异常时保持「待检测」，发现威胁或图片解码失败时标记「已隔离」。这两种状态均不能预览、下载、共享或用于发布。上传者可在素材库重试检测。图片读取仍经过控制台鉴权，返回 `no-store`、`nosniff`，不会生成可绕过项目权限的公开链接。

在 `.env.server` 配置可信内网的 ClamAV 扫描服务：

```dotenv
LEDGER_ANTIVIRUS_HOST=clamav.internal
LEDGER_ANTIVIRUS_PORT=3310
LEDGER_ANTIVIRUS_TIMEOUT_MS=10000
```

ClamD TCP 协议本身不提供认证或加密，扫描端口应仅向应用服务所在的可信网络开放。应维护病毒库更新；任何单项扫描均不能代替格式、资源和访问权限校验。协议依据：[ClamAV ClamD Protocol](https://docs.clamav.net/manual/Usage/ClamdProtocol.html)。

## 部署与数据保留

- 服务启动沿用现有 `sql/schema.sql` 初始化入口，创建台账所需的文章、版本、事件、素材和引用表。新增表均使用幂等 `CREATE TABLE IF NOT EXISTS`。
- 素材为二进制 BLOB，随管理库备份；继续使用项目要求的 `mysqldump --hex-blob --result-file`，不能以文本解码方式转存。
- Markdown 编辑器与渲染依赖随前端构建打包，辅助资源位于 `vendor/vditor/dist`，不依赖外部 CDN。HTML 渲染进行净化，图片只接受本站素材 ID 地址。
- 没有后台自动删除已发布版本或引用素材的任务。删除草稿只删除当前私有草稿，已发布正文和历史版本保留。
