# 数据对象：结构复用、已有值与可选懒加载

## 引用不是强制重新取值

数据对象用于组织结构。相同的字段定义或数据对象可以复用，但不能因此覆盖当前对象已经收到或已经写入的值。

取值顺序：

1. 当前对象的具体子字段路径已赋值时，直接使用该值。`0`、`false`、空字符串、空列表及显式 `null` 都不等于路径缺失。
2. 路径缺失时，检查该字段的“引用用途”。“仅复用结构”不调用来源，不从被引用变量的同名结果补值。
3. 只有“引用取值”的缺失字段，才解析它按 ID 绑定的变量或常量，再填充当前对象路径。

这是数据对象子字段的取值契约，不表示调用方可以通过传入同名独立 API、名单、衍生或模型结果，伪造引擎已经完成取值。独立运行时变量仍走可信来源和根执行缓存。

## 配置入口

在“变量管理 → 数据对象”编辑对象和字段：

| 配置 | 作用 | 默认/兼容行为 |
| --- | --- | --- |
| 字段“引用用途：引用取值” | 子字段缺失时补取引用来源 | `VALUE`；兼容原有引用配置 |
| 字段“引用用途：仅复用结构” | 只复用定义，不加入该来源的运行时依赖 | `STRUCTURE`；可用于列表内部字段的定义复用 |
| 引用数据对象 | 复用对象结构，不自动复制另一个对象的值 | 保留 `refObjectId` 关联 |
| 对象“懒加载引用字段” | 只在实际读取缺失的引用型叶子时取值 | 默认关闭；旧快照没有该设置时也按关闭处理 |

懒加载关闭时，按既有执行计划补齐本次规则所需的缺失引用字段；开启后，读取一个引用叶子不会连带解析未读取的引用叶子。普通输入字段、仅复用结构的字段以及已有值均不产生额外来源调用。对象/对象列表等非叶子容器不套用叶子懒加载。

“全部”不表示扫描并执行整个项目的变量，也不为了记录历史而计算未引用的来源。图规则已有的分支执行边界保留。

## 执行一致性

- 页面预览、已发布规则及子规则使用同一对象引用计划。
- 模型入参和衍生表达式优先使用对象已经赋值的实际路径，而不是直接跳到被复用变量的路径。
- 开启懒加载的引用字段，其来源状态读取也按需触发；子规则退出后恢复父规则的状态解析上下文。
- 父子规则仍共享根执行缓存：同一来源的空值、失败和成功结果不会因重复读取而重新调用；接口内部失败重试保留。
- 普通对象写入、删除、清空保持原有 Map 语义，日志/追踪序列化不会触发尚未访问的引用。
- 引用用途和懒加载策略进入发布快照。修改对象配置后，旧规则保持旧策略，重新发布才生效。

## 历史日志

对象实际收到的子字段按其自身字段 ID 保存。三方日志中的同 ID 映射不能覆盖这份输入，包括显式 `null`。仅复用结构的字段按对象自身路径处理，不误归类成被复用变量的 API/衍生结果。
