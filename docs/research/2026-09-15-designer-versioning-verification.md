# 规则设计器与版本生命周期改造验收记录

本次按已确认的 2026-09-14 需求实施，在当前 master 工作区完成，不提交或推送混合中的历史改动。用户要求不使用子智能体后，后续修复和验收均由当前任务直接完成。

## 已实施的行为

- 九类设计器统一为“编译、保存、发布、测试”。编译返回实际 QLExpress 和发布前检查报告，不创建草稿；保存由服务端先编译再持久化；测试直接使用当前页面配置，未保存也可执行。
- 默认查看最新正式版本，或按指定来源 ID 打开；进入、编辑、无改动切版不写草稿。生产版本编辑保存为独立草稿；草稿编辑选择新增或覆盖，覆盖使用精确 ID 和乐观锁。
- 改动后切版支持保存并切换、直接放弃、取消。保存成功后进入原定目标；失败保留修改。连续保存/发布弹窗不会互相误取消。
- 草稿可删除，保留软删除与生命周期审计；最后一份草稿删除后清理兼容内容投影。切换空白来源会清空脚本、引用或表格模型，不复用已删除内容。
- 发布保存后选择新增正式版本或覆盖指定业务版本，提交审批。正式业务版本号仅在审批通过并激活时生成。覆盖通过新增不可变快照和更新业务版本绑定完成，不改写历史制品。
- 指定版本按业务绑定 ID 执行；未指定默认 LATEST。覆盖 v1 会更新固定引用 v1 的调用，但不会把 v2 的最新版指向改回 v1。服务端和 SDK 支持 ID/指定版本调用、一次执行内的引用解析复用、代次缓存失效和调用追踪。
- 固定版本的字段校验读取对应制品快照；导入制品的规则与版本引用必须有显式 ID 映射。循环和受影响的字段兼容性在提交、激活时校验。
- 审批历史版本号冲突不再使用草稿修订号占用正式版本号；异常不再被吞掉后表现为 rollback-only。未操作用户原有审批 37。
- 状态放在名称下方信息行最右侧，字段信息在最左侧。UI 调整技能用于操作层级与主题令牌：发布为主按钮，其余为次按钮，文字、背景、hover、focus、禁用态与主题联动。
- 修复真实 UI 发现的项目元信息晚到导致页面重建、正在填写的表单消失的问题。
