# 规则配置完成后的操作耗时与修复

## 对照结果

在同一张评分卡上，从点击按钮计时，直到页面显示可用结果。每组预热 1 轮，正式测量 8 轮，逐轮交替新旧版本的先后顺序。表中为中位数，单位为毫秒。

| 用户操作 | 修复前 | 修复后 | 实际观测 |
| --- | ---: | ---: | --- |
| 检查 | 729 | 480.5 | 校验报告可见，短编译任务从 3 次 HTTP 往返降到 1 次 |
| 编译 | 721.5 | 406 | 画布显示编译完成，保留可供保存引用的任务 ID |
| 保存 | 549.5 | 390 | 生成草稿并切换到实际修订；同账号、同授权版本、同项目可复用当前页的业务目录 |
| 打开发布确认 | 834.5 | 242 | 已保存草稿按真实修订和锁版本预检，同时读取发布版本。此阶段的业务请求从 10 个降到 2 个，原先还包含保存后陆续发出的目录请求 |
| 确认提交审批 | 896.5 | 786.5 | 同一提交请求中的完整分析从 3 次降到 2 次 |
| 批准并生效 | 1,153.5 | 1,093 | 包含批准请求和审批详情刷新；仍需验证依赖、回归证据并激活制品 |
| 打开已发布版本的测试窗口 | 62 | 59 | 输入结构就绪，可执行测试 |
| 执行测试 | 94 | 98.5 | 均返回本轮配置的分数。单次测试未观察到稳定加速 |
| **一轮操作的累计等待** | **5,017.5** | **3,551** | **减少 29.2%**。每轮先累加八段等待，再取中位数 |

八轮累计等待的原始值分别为 `4869, 4855, 4831, 4959, 5076, 5366, 5459, 5306` 和 `3555, 3426, 3521, 3547, 3578, 3540, 3564, 3857`。计时排除了录入、阅读、人工审批间隔和不同页面之间的导航。

## 定位到的原因

- **编译结果本已就绪，页面还要等待通知，再取一次任务结果。** 设计器现在请求短时异步返回。任务在等待窗口内完成便返回结果，耗时较长的仍返回同一任务 ID，继续走授权查询。同步请求、后台任务入队和实际执行仍分别遵守对应的来源检查。
- **每次沿历史版本核对引用来源，会为同一版本重复读取制品包。** 版本行只读取核验所需的身份和摘要列。同一次遍历复用已核实的制品摘要，每个版本绑定仍逐一比对。后台编译在出队时重新核对；下一次异步任务或发布请求不能沿用上次的证明。冻结版本测试也复用已取到的制品实体。
- **字段解析为已有映射执行了 4 次无效 SQL。** 输入和输出各读两次旧名称映射，调用方实际上只使用稳定 ID 和引用类型。移除这 4 次读取，继续读取输入字段上原有的校验覆盖配置。
- **已保存的草稿在打开发布确认时再次按临时画布编译。** 内容完全匹配时直接预检已保存修订，锁版本或内容变化则拒收旧结果。未保存的修改仍先校验，再保存。提交事务使用已经通过回归门禁的修订检查版本图；批准生效时独立校验，锁、覆盖代次和回归门禁均保留。
- **校验成功后页面偶尔没有报告。** 从冻结版本切入实时资源时，同一字段 ID 在两个目录中的 JSON 类型可能是字符串和数字。以前刷新元数据会改写画布，刚返回的报告因此被判过期。现在保留原绑定 ID 的表示，实际配置或引用内容在校验期间变化时提示重新检查。旧版在预热中出现过一次需要再次点击检查，新版对照未发生。
- **测试来源和审计存在偏差。** 从发布版本另存后，测试明确使用已保存草稿及其锁版本；继续编辑时才使用画布预览。读取测试结构按实际目标模块及 ID 记为 READ，读取修订预检也记为 READ。项目工作台的“最近一次执行”携带稳定项目 ID 和 trace 打开日志，普通日志页原有筛选独立保留。

## 验证范围

对照使用本机两套独立 MySQL、Redis 和日志目录，均运行生产前端构建、JDK 17 服务制品和 Chrome。基线规则代码来自 `d0104f2c`。种子数据通过浏览器新建项目、字段、评分卡并完成审批。复制种子库时对 101 张表逐表核对行数和校验和，共 1,215 行。最终对照开始前，两边同一规则均有 21 条修订。

每轮通过页面修改初始分，依次检查、编译、保存、提交、批准，再从生产版本执行并断言实际输出。业务没有外部调用，计时用例未启用固定回归场景。固定用例缺失或过期、锁冲突、异步超时、冻结及外来制品来源由回归测试另行覆盖。该组数据衡量管理端操作等待；生产并发、外部供应商及大型模型推理的耗时需按相应业务另测。

另外在真实前后端中新增启用的固定用例，验证缺少回归证据时，已保存草稿直接显示具体校验错误，未产生提交请求。从项目工作台查看最近执行、返回普通日志恢复旧筛选，以及另存后按草稿锁版本测试，也通过浏览器操作验证。

合入 `efa05154` 后的本地验证包括全模块构建、服务启动、前端 3,741 项单测、ESLint、生产构建和 578 项生产包浏览器回归。后端 3,033 项中通过 2,965 项，68 项按环境条件跳过，零失败或错误。
