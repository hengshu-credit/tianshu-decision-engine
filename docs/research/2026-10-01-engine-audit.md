# 天枢决策引擎整体审查记录

## 审查范围

本次按业务人员配置路径和线上执行链路走查了项目、变量/数据对象、衍生变量、外数 API、规则设计器、测试输入、表达式追踪、开放 API、HTTP/Java SDK、离线迁移、执行状态、缓存、连接池、限流熔断和 Redis 跨节点状态。

当前产品能力已经覆盖九类规则、变量与数据对象、外数 API、模型、函数、审批发布、离线迁移、开放 API、追踪树和账单。主要风险集中在配置复杂度、配置错误发现时机、运行态依赖的可解释性以及少数单节点内存状态。

## 已修复

### 统一外数配置的测试报文生成

统一 `executionConfig` 中的请求字段使用 `REFERENCE/PATH` operand 按 ID 保存。原来的“生成测试 JSON”只扫描旧版 Header、Query、请求映射和模板字符串，忽略了这些 operand，因此复杂 API 的测试输入可能生成空对象。

现在会扫描顶层请求字段、请求分支和多步请求字段中的业务引用，自动生成嵌套 JSON；`API_CONTEXT`、响应路径和步骤上下文不会被误当作调用入参。新增测试覆盖变量引用和默认值。

### 统一链路的前置校验

前端现在在保存前检查：

- version 必须为 2；
- 字段 ID、分支 ID、步骤 ID 唯一；
- 位置和目标路径合法且不重复；
- Header 不允许被业务变量覆盖；
- 异步模式必须有步骤；
- 步骤不能引用尚未完成的步骤；
- 回调地址必须使用公网回调模板；
- 轮询必须配置完成条件。

后端仍保留最终校验，前端校验只负责把错误提前显示在配置页面。

### 配置损坏和数据库错误提示

统一链路 JSON 解析失败时，编辑器不再直接抛出页面异常，而是在配置区域显示修复提示。数据库只读查询遇到连接池初始化、账号权限、连接拒绝等典型错误时，提示会给出对应的检查路径，保留原始错误用于定位。

### 模型筛选可访问性

模型编码和模型名称筛选输入补充了可访问名称；真实浏览器测试改用文本框语义定位，模型测试流程已通过。

### 设计器编译任务的跨节点读取

后台编译任务继续使用本地线程执行，并将任务状态、模型摘要和完成结果写入 Redis（Redis 不可用时回退本地内存）。另一节点可以读取已完成任务并复用编译结果，任务快照 30 分钟自动过期，避免长期堆积。

### 客户端远程 Bean 函数注册

客户端收到函数推送时，远程 Spring Bean 尚未完成初始化属于可恢复状态。注册器现在记录为 `WARN`，订阅器明确标记“更新暂缓、操作可重试”；Bean 出现后原推送可以再次成功注册，不再把测试或启动阶段的暂时缺 Bean 打成错误堆栈。

### 开放规则执行队列

开放 API 请求超时或线程中断时，执行器现在同时取消任务、从队列移除并调用 `purge` 清理取消项，避免慢请求或大量超时请求把已取消任务留在有界队列中，导致后续健康请求被误判为队列已满。

## 现状中仍需持续治理的事项

### 配置复杂度

外数 API 的统一编辑器已经按请求、响应、多步和策略分组，但多步、异常树、重试、鉴权和报文留存仍会让非技术人员看到大量低频字段。下一步应增加“简单同步 API”快速路径：只需要方法、地址、请求字段、响应样例四步；只有启用异步、脚本、条件分支或高级重试时再展开高级区域。所有高级配置仍保留，不改变直接 SQL 和脚本能力边界。

### 衍生变量和历史统计

衍生变量已按 ID 绑定并限制历史窗口最多 100000 条、64 MiB，但多层关联仍在应用内对候选行做逐层扫描，复杂关联的 CPU 成本随窗口和关联层数增长。需要在真实数据量上压测，并评估按项目、根规则、时间和历史字段建立覆盖索引或预聚合表。

### 外数执行与横向扩容

Redis 已承载回调、响应缓存、外数流控和熔断状态；Redis 不可用时部分保护会退回单节点内存状态。生产集群需要把 Redis 可用性纳入启动就绪检查，并明确“降级为单节点”还是“拒绝可能失控的外数调用”。

开放规则线程池、外数连接池和模型执行池都有边界，但请求超时后底层供应商连接若未及时响应仍可能占用工作线程。需要用压测验证连接读取超时、线程池队列满、取消任务和慢供应商组合下的尾延迟与恢复速度。

### 数据库真实验证

本机真实浏览器走查中，数据库只读查询流程能够打开 SQL、识别参数并执行；当前 `rule_engine_mysql` 数据源返回 `Access denied for user 'root'@'localhost'`，原因是数据源凭据和数据库权限不匹配。应用已显示可执行的账号/权限检查提示；正式验收需要把数据源切换为最小权限只读账号后再重跑查询流程。

### 追踪和报文留存

规则结果、外数调用、步骤、重试和变量赋值已经有稳定关联键。后续需要以大报文和高并发压测确认诊断留存上限、脱敏副本、原始报文查询和日志写前日志不会反向拖慢主执行路径。
