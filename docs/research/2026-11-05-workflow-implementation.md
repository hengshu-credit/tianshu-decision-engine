# 发布、测试、排障与台账流程实施记录

基线：`076b1ef2`，分支 `master`。本轮包括六条流程改进，以及后续确认的事件/类型 CRUD、每事件独立状态枚举、弹窗间距和唯一编码要求。

## 已实现的行为

| 范围 | 实现 | 验证重点 |
|---|---|---|
| 发布就绪概览 | 在规则生命周期页集中显示当前修订、线上修订、依赖预检及回归统计；可进入现有回归报告抽屉 | 报告必须同时匹配修订 ID 和锁版本；过期、缺失、未复核不能显示为通过；原审批与发布门禁保持 |
| 版本来源与执行模式 | 测试页单独显示版本来源和“真实联调”，列出结构化配置识别到的 API、DB、SFTP、模型取值及名单写入；显示计费与动态引用边界 | 不将草稿等同于离线试算；未识别到不代表没有副作用；大整数引用 ID 保持精确 |
| 日志排障 | 关联失败模块/规则、执行时快照、稳定 ID 配置入口、调用状态、名单任务 ID 和重试条件 | `QUEUED` 只表示持久化交接，不能声称写入完成；不使用当前规则冒充历史快照；迟到回放不能覆盖新打开的日志 |
| 血缘按需扩展 | 按起点和方向逐层查询，资源及关联查询继续经过 MyBatis 权限过滤；缓存只存在于一次请求内 | 不穿过不可见中间节点；下一请求重新鉴权；默认双向查询经过上游项目时不读取整个项目的兄弟分支 |
| 台账日历 | 月份统计、每日最多 8 个预览、关联事件分别批量查询 | 保留时间与 ID 排序、去重、权限和每日数量；无筛选引用校验时为 3 条数据查询，不随日期和预览数量增长 |
| 编辑保护 | 复用公共离开保护，补齐项目、名单、计费、模型、函数、变量/对象/枚举/导入和账户主要写入入口 | 保存锁覆盖异步验证；失败保留输入；关闭和刷新可取消；多个弹窗的基线独立，不误把其他弹窗修改标为已保存 |
| 事件与类型管理 | 台账增加“事件与类型”Tab；事件分页查询，事件和类型均可新增、编辑、删除 | 事件遵守项目及作者权限；类型修改需要全局台账管理权限；已引用资源拒绝删除 |
| 独立状态枚举 | 每个新事件自行配置状态值和可选显示名称，再选择当前状态；枚举按事件独立持久化 | 当前状态必须属于该事件枚举，状态值唯一；旧客户端更新时保留已有枚举，旧事件保留历史状态含义 |
| 编码与名称 | 事件及类型均有必填编码和名称，分别使用数据库唯一索引；编辑通过稳定 ID 关联 | 用户编码不改大小写、不自动转换；重复编码保留输入并报错；删除后编码仍保留，不复用历史编码 |
| 弹窗布局 | 台账弹窗正文上方增加 16px 间距，状态枚举行使用响应式排列及主题变量 | 真实事件弹窗测得标题与表单间距约 16px；保存后重新编辑可回读枚举 |

## 边界与升级方式

- 血缘展示最多 1000 个已加载节点，超限明确拒绝并提示更换具体起点或减小深度，不返回伪装完整的截断图。配置治理中的完整消费者检查保留，避免削弱删除、发布依赖保护。
- JSON 来源引用先按 ID 文本缩小候选，再按 `refType/refId` 精确识别；这仍可能扫描相关 JSON 配置列。当前改动不等于建立了所有动态引用的数据库索引。
- 测试影响清单来自所选版本的字段结构和模型内容。脚本、函数及子规则的动态副作用不能静态穷尽。未新增伪“纯计算模式”；历史回放继续使用现有离线快照执行机制。
- 新表为 `rule_ledger_type`、`rule_ledger_event_type`、`rule_ledger_event_state`。`schema.sql` 仅包含表结构；旧固定类型由依赖数据库初始化完成的迁移逻辑幂等转换，保留用户改名与删除状态。
- `SchemaSyncService` 补齐编码列及唯一索引，只为缺失编码的历史记录生成 `EVENT_<ID>`、`TYPE_<ID>`；旧固定类型采用原枚举编码。已有编码不会被重写。该步骤需要与现有结构升级一致的 DDL 权限，失败会阻止启动。
- 新事件/类型创建必须提供编码；更新缺省编码字段时兼容保留已有编码。引用仍按 ID，不通过编码或名称回溯关联。
- 状态枚举支持 1–50 项，状态值最多 24 字符，显示名称最多 80 字符；显示名称可留空，值原样保存。独立状态不会修改其他事件的枚举。
- 事件类型筛选匹配文章自身类型或其可见关联事件的类型，不通过不可见事件泄露关联关系。

## 编辑入口盘点

完整入口清单见 [80 个弹窗/抽屉入口](2026-11-05-editor-protection-inventory.md)，分布于 44 个组件文件。静态标记与真实覆盖分开记录：

- 配置详情页和九类设计器沿用现有 `configurationDraftMixin`、`ruleDraftMixin` 等专门保护。
- 列表内编辑弹窗复用 `configurationDialogsMixin`，统一基线、关闭、浏览器刷新与工作区保护；保存锁仍由具体业务请求维护。
- 变量导入保留已有导入锁，新增离开提醒；枚举读取增加请求代次，旧字段响应不能写入新字段表单。
- 日志、版本和运行详情按只读信息处理，保留关闭能力，以请求代次防止迟到结果覆盖；不为只读查看添加“未保存”提示。
- 账户表单仅在内存保留待提交凭据，未加入浏览器持久存储；实际账户授权和密码策略仍由服务端控制。本轮没有通过真实 UI 修改任何账户权限或密码。
- 清单不代表每个历史页面的每种隐藏状态都经过真人测试；真实外部接入、权限角色组合及生产负载仍需对应环境验收。
