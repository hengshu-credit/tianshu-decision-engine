# 天枢决策引擎优化实施记录（2026-09-24）

## 已实施

| 优化项 | 实施内容 |
|---|---|
| 统一校验协议 | `RuleValidationIssue` 和 `GovernanceIssue` 增加业务标题与下一步动作；校验报告优先展示服务端下一步。 |
| 六项发布进度 | 规则详情增加基础信息、输入输出、设计内容、发布前校验、测试样例、审批发布六项进度，并支持点击进入下一步。 |
| 分层配置 | 变量页、规则测试页复用 `ConfigLayerGuide`；数据库页保留基础配置与高级设置分层。 |
| 审批可解释性 | 审批详情增加动作、字段差异、依赖影响和生效条件摘要。 |
| 异步日志/计费 | 根执行日志与引擎计费进入有界异步队列；队列满时回退同步写，保证不丢审计/计费；新增 `/api/rule/ops/execution-metrics`，同时返回持久化、来源解析和开放执行线程池指标。 |
| SQL 智能配置 | 前后端只读 SQL 语料支持安全 `WITH ... SELECT`；仍拒绝 DML、锁定、可执行注释和多语句。 |
| 组件拆分 | 新增 `ConfigLayerGuide`，变量和规则测试共用同一层级引导组件。 |
| 版本实验联动 | 实验详情增加版本与流量关系摘要；保留版本对比、回滚入口。 |
| 运维门禁 | 增加容量、备份恢复和真实环境 E2E 操作手册，复用现有质量门禁脚本。 |
