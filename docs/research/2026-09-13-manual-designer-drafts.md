# 设计器按需暂存草稿

目标：新建规则、进入设计器、切换版本和编辑内容不创建草稿；只在设计器明确暂存时写入。

实现约定：未指定来源时优先最新正式版本，没有正式版本时使用最新已保存修订或初始内容；指定版本必须精确加载。所有编辑先发生在页面副本，历史版本不被直接写入。已有暂存草稿可通过版本选择器打开。

暂存沿用服务端存储，仅在用户点击“暂存草稿”或“暂存并检查”（或保存快捷键）时执行。关闭/切换时对未暂存内容提示确认，不再自动写浏览器恢复草稿。已有其他暂存草稿或待审批修订发生冲突时保留页面内容并解释原因，不自动覆盖或切走。

## 实现范围

- 新建规则只建立未发布的规则定义和初始内容，不生成 DRAFT 修订。“创建并继续配置”直接进入对应设计器。
- 九类设计器共用版本选择、页面副本编辑、未暂存提醒和显式服务端暂存逻辑；历史来源按记录 ID 精确加载，不以版本号猜测 ID。
- 规则详情的编辑入口及规则集历史弹窗只导航/载入版本，不在进入设计器前创建或恢复草稿。
- 首次暂存调用 `POST /api/rule/definition/{definitionId}/revisions/temporary-draft`，携带来源 ID 和当前页面内容，由同一事务创建并保存。已打开的 DRAFT 继续通过原保存接口和乐观锁更新。
- 暂存成功切换到服务端返回的草稿 ID，并保留项目范围。重新从默认入口进入仍打开最新正式版本；需要继续草稿时，在版本选择器选择“暂存草稿”。
- 服务端既有草稿、待评审约束和发布审批链路继续保留。不会自动覆盖别的草稿、修改历史快照或发布内容。没有删除已有用户草稿。

## 2026-09-14：设计页提示轻量化

根据用户确认，九类设计器的加载、只读及来源读取失败不再使用模态遮罩，改为页内 info 信息条。移除遮罩背景、浮层定位、阴影和 `aria-modal`；使用项目主题背景与文字色，明暗主题正文对比度均不低于 4.5:1。

加载或失败期间保留编辑与保存保护；只读用户可从信息区切换版本、返回，不会触发创建草稿。失败时新增“重试”，沿用原版本记录 ID 和防过期响应逻辑，成功后加载该版本内容并恢复编辑。未暂存修改的离开/切版确认及删除确认未移除。

验证结果：

- 修改前相关单测 113 项通过；新测试先复现旧模态语义及缺少重试，修复后通过。夜间主题对比度问题也先由浏览器测试复现（1.40:1），再调整主题色。
- `npm test -- --maxWorkers=4`：178 个文件、2121 个测试通过；重试覆盖九类设计器非空模型恢复、请求未完成时禁止保存、无草稿写入。
- `npm run lint` 和 `npm run build` 通过，既有大分块提示仍存在。
- `npm run test:e2e:dist -- --workers=2`：144 项全部通过，含九类慢加载、原地重试、只读切版、明暗主题对比度、手动暂存和未暂存确认。
- `npm run dev` 临时端口 9092，配本机模拟 API 手动完成加载 → 失败 → 重试 → 编辑 → 切版 → 取消确认，确认内容恢复、修改保留，浏览器无报错。临时服务与页签已关闭，未主动重启或停止用户已有服务。

本次只修改前端交互，不改后端及保存契约。模拟浏览器验证不是本次真实数据库持久化验收。高并发浏览器首次回归遇到 Windows 资源分配失败；降低并发、修正过渡状态测试定位后重新跑完整套件通过，没有跳过或放宽断言。
