# 衍生变量与内部进件统计

变量管理新增「衍生变量」（`DERIVED`），与「规则计算结果」（由规则动作写入）区分。

## 配置方式

- **上游字段计算**：使用现有字段/函数/运算表达式，字段按 ID 绑定。可引用另一衍生变量；引擎按上游依赖顺序计算，拒绝循环。调用方传入的同名衍生结果不能跳过计算。
- **内部进件统计**：选择时间窗口、最外层规则/执行项目/全局范围，配置关联路径、属性筛选、主体 key 和聚合方法。地理半径是可选筛选条件，不是独立的数据来源。

历史统计通过服务端执行；SDK 请启用 `serverSideExecution(true)`。本地离线执行不具备内部进件数据库。

## 常见指标

| 指标 | 配置 |
| --- | --- |
| 最近 30 天进件数 | 时间窗口 30 天，不配置关联，方法「进件数」 |
| 最近 30 天进件人数 | 方法「主体去重数」，主体 key 选择申请人标识 |
| 相同设备关联人数 | 第一层：本次设备字段匹配历史设备字段；主体 key 选择申请人标识 |
| 联系人关联申请人的历史申请金额合计 | 第一层：本次联系人列表匹配历史联系人列表；第二层：上一层的申请人标识匹配历史申请人标识；统计属性选择申请金额，方法「求和」 |
| 相同联系人关联申请人的最新风险属性均值 | 同上关联链；主体 key 选择申请人标识；「每个主体只取最新一条」；属性选择风险数值，方法「平均值」 |
| 周边一公里关联人数 | 配置本次中心经纬度、历史经纬度字段和 1000 米半径，再选择主体去重 |

关联采用半连接：同一条历史进件在一层被多个联系人命中时，只保留一次。每层可配置多个标量字段组成联合 key，字段之间按同一条历史记录匹配，不通过字符串拼接组成 key。单字段列表关联使用任一元素相等；联合 key 不接受多值列表，避免不同列表元素被错误组合。最多 8 层，每层均应用同一时间窗口和作用范围。属性筛选条件之间为 AND。

全局统计中的属性关联仍使用字段 ID。跨项目要复用同一个全局字段；名称相同但 ID 不同的项目字段不会被合并。

## 统计口径

- 正式成功完成的服务端规则执行在根调用完成后写入 `rule_application_history`，保存原始/已解析字段及声明输出的 ID 快照；不重复写入子规则。引擎成功返回的业务拒绝结果同样是一次完成进件。
- 单变量预览、规则测试不写入进件历史。本次请求始终排除；统计区间为 `[本次开始时间 - 窗口, 本次开始时间)`。天表示滚动 24 小时，不是自然日。
- 进件数默认按根执行记录计数；如果业务请求重试应视为同一进件，将业务请求编号设为主体 key，并选择去重计数或「每个主体只取最新一条」。
- 主体 key 的任一项为空或空白字符串时不参与主体去重；不会把多名缺失标识的申请人当作同一个人。关联时空 key 也不会相互命中。
- 数值聚合不将数字字符串自动转换为数值。总体方差除以 `n`，样本方差除以 `n-1`；标准差为相应方差的平方根。
- 空属性不参与值聚合；空集合计数、求和、字符串长度合计为 0，均值、最大最小值和方差/标准差为 `null`；样本统计少于两项为 `null`。配置变量默认值时，沿用现有变量默认值规则。
- 字符串长度为各非空值的 Unicode 码点数合计。自定义聚合函数接收一个值列表参数，返回类型必须与衍生字段类型一致。

## 上游入参与发布

「生成上游入参」、保存后的变量测试、规则测试和 API 文档复用字段依赖解析。只展开本次请求侧的字段，递归到原始输入；历史匹配字段、主体字段、历史属性不会成为调用方必填参数。常量也不会成为输入。

已发布制品包含衍生配置及其引用的变量、对象字段和函数快照。运行时按 ID 解析，不用保存时的展示名称回查，因此字段改名不会改变历史关联身份。

身份证年龄可通过现有 `idCardAge` 配置计算日期和周岁/年份差口径。身份证登记地址码不是当前户籍地址；如需当前户籍地，应绑定可信的上游信息来源，不把截取地址码当作实时户籍查询。

## 数据与容量边界

- 新表由 `schema.sql` 或启动时的增量结构同步创建，不清空既有表。统计历史从启用本功能后的正式进件开始；旧执行日志只有名称映射，**不会自动猜测 ID 并回填**。
- 目前统计快照接入服务端规则正式执行；实验路由/影子执行和 SDK 离线日志不作为该表的数据来源。
- 跨环境导入制品的字段 ID 仍属于源环境；在建立本地字段 ID 映射之前，不采集导入制品的历史，并明确拒绝其历史统计执行，避免与本地同号字段混淆。
- 查询使用作用范围与时间索引，有 10 秒数据库查询超时；单次窗口最多 100000 条记录、64 MiB JSON 字符存储预算。超限明确失败，不返回部分样本的统计值。大规模在线特征计算仍需索引化主体/关联明细及增量预聚合，不应靠扩大全量窗口上限解决。
- 没有新增自动删除历史数据的任务。上线时应结合业务保留期、访问权限及敏感信息管理策略配置独立的存储与清理流程。
