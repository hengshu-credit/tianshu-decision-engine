# 系统配置

控制台一级菜单“系统配置”管理全局品牌、通知邮箱、登录与安全、对外结果码和变更记录。配置作用于整个部署实例，不随项目切换。

## 权限与生效

- 使用独立的 `system:view`、`system:edit`、`system:submit`、`system:mail-test`、`system:audit` 权限。项目权限覆盖不能授予系统配置权限，全局只读账户不能修改或测试发信。
- 老安装升级后，管理员重新登录时，现有权限目录同步流程会将新增权限授予超级管理员角色；已经撤销的旧授权不会恢复。
- 基础品牌信息保存即生效；通知邮箱、访问策略和结果码映射复用既有草稿、预检、提交、审批流程。待审批配置不覆盖已生效值。
- 配置按分组保存版本，冲突时拒绝覆盖。底层表结构由 `schema.sql` 创建，四个空配置分组由启动迁移幂等补齐，默认值来自内置值及现有部署配置。
- `.env.server` 中的旧邮件、注册及找回配置作为迁移缺省；数据库生效配置接管后不修改该文件。操作系统环境变量、Java 系统属性及命令行的显式覆盖优先，对应配置组在页面中只读。
- 品牌在当前页面保存后刷新，其他页面进入或重新获得焦点时更新。对外映射在当前节点事务提交后失效缓存，其他 server / HTTP runtime 最迟在下一次 5 秒缓存刷新时更新；本地 Java SDK 随现有规则同步心跳更新，失败保留最后生效快照。

## 品牌与通知邮箱

系统名称、副标题、Logo、浏览器图标统一应用到登录/注册/找回页面、导航、浏览器标题、新导出的接口文档及邮件。操作页面自身的“注册账户”“设置新密码”等标题保留。

Logo 和浏览器图标都可填写 HTTP(S) 图片地址、以 `/` 开头的本站图片路径，或上传图片；两种来源互斥。浏览器图标未单独设置时自动跟随当前 Logo。图片地址由浏览器直接加载，服务端不代为下载；外部地址需允许访问，HTTPS 页面应使用 HTTPS 图片地址。

上传支持 JPG、PNG、SVG、GIF、WebP、BMP、ICO，原文件最大 1 MB、宽高最多 2048 像素。非 JPG/PNG 格式先在浏览器图片上下文中解码为静态 PNG（动图取当前帧、SVG 转为像素），服务端再次验证并重编码为 PNG，按资源 ID 存入数据库。已保存品牌引用的图片才允许匿名读取，避免多 server 部署依赖单节点文件。图片地址可以保留原始 SVG 或动图。

基本信息右侧顶部展示导航标题、副标题与浏览器页签，下面直接复用登录页组件；导航品牌预览复用侧栏品牌组件，字体、颜色、间距和控件样式随实际页面及当前主题一致更新。

只设置一个通知邮箱，它同时作为发件地址和 SMTP 登录账号；填写 SMTP 主机、端口、STARTTLS 或 SSL/TLS、授权码。授权码留空保留、填写替换，不回传明文，不写入浏览器持久缓存或变更摘要。本页面不提供清除授权码或另设发件人/回复邮箱的选项。

注册验证、密码找回、测试邮件及系统配置变更/超管恢复通知通过同一邮件服务发送。系统事件在事务提交后异步发送至已验证邮箱的有效超级管理员；无可用通知邮箱或收件地址时不发送，不影响原操作。发送失败记录在变更日志中。测试邮件使用当前表单及当前本人草稿的凭据，接收地址仅用于该次测试；SMTP 接受不等于最终送达。

邮件使用 HTML 正文和纯文本备份，上传 Logo 通过 CID 内嵌 PNG；配置图片地址时使用对应地址，本站路径以控制台访问地址解析。导出的接口文档也保留配置的图片地址。页眉为通知标题与品牌组合，正文包含通知内容和操作入口，页脚只保留“上海衡枢真信科技有限公司”和官网。用户输入以文本转义，验证/找回链接仍使用原有令牌消费、有效期及安全流程。

## 页面水印

在“基本信息”中打开“页面水印”并保存后，全局启用水印，默认关闭。与基本信息共用 `system:edit` 权限、版本冲突检查和变更记录，不需要审批。已有配置无需手工迁移。

水印平铺覆盖所有已登录页面（包括暂无权限页面、弹窗、抽屉及全屏区域），默认单行显示“系统名称 用户名 本次登录时间”，例如 `天枢决策引擎 admin 2026:10:10 12:00:00.121`。时间格式为 `YYYY:MM:DD HH:mm:ss.SSS`，精确到毫秒，按浏览器本地时区显示，来自服务器会话创建时间，刷新和切换页面不会改变，重新登录后更新。未登录、退出登录或关闭登录认证时不显示。水印不拦截点击、输入与滚动，并适配深浅主题。

页面水印配置区支持以下选项，编辑时直接在当前页面预览，没有独立预览区。未保存的预览仅存在于当前配置页内存中，取消修改、切换配置分组或离开页面后恢复已生效配置，保存失败不会影响其他用户：

- **水印内容**：最多 200 字符，可输入文字和换行，并通过按钮追加 `{系统名称}`、`{用户名}`、`{登录时间}` 动态字段；默认内容为 `{系统名称} {用户名} {登录时间}`。内容按纯文本绘制，不执行 HTML 或脚本。
- **透明度**：0–100%，数值越大越淡；0% 不透明、100% 完全透明，默认 88%。
- **排列方式**：斜向平铺（默认）、水平平铺、竖向平铺。
- **密度**：稀疏、标准（默认）、密集，对应水印单元的水平及垂直间距为 180、100、40 像素。

关闭水印时仍可编辑并保存其配置。旧配置自动补齐缺省值，旧版页面保存基本信息时不会覆盖已设置的水印选项。

保存后当前页面立即更新，其他已登录用户的可见页面每 5 秒同步已保存配置，重新获得焦点时也会立即刷新，无需重新登录或具备系统配置查看权限。每个用户的水印分别使用本人的用户名和本次登录时间，管理员的预览值不会共享。网络异常时保留最后一次成功获取的配置，恢复连接后继续同步。水印用于画面身份标识，不替代访问权限控制。

## 对外结果码映射

源系统码来自 `PlatformCode`，只读且不可新增/删除；每项可配置对外 `code` 和描述（响应字段 `message`）。留空沿用对应默认值，关闭映射时全部使用标准值。code 为字符串，保留前导零；允许多个源系统码共用同一个对外 code，描述可分别配置。

例如，`100001` 和 `100002` 都可以映射为 `E1000`，描述为“参数不正确”。引擎内部依旧区分入参校验失败和必填字段缺失。不能通过合并后的 code 判断成功、重试、等待或鉴权结果，应使用 `success`、HTTP 状态、`executionStatus` 与原始标准码元信息。

启用映射时，对外 HTTP 响应附带：

| Header | 含义 |
|---|---|
| `X-Rule-Standard-Code` | 此次响应的原始标准码，避免多对一映射后的反向歧义 |
| `X-Rule-Code-Mapping-Version` | 使用的映射版本 |

控制台管理接口仍使用标准码；SDK 内部同步、鉴权和重试解析使用标准码，交给业务方的结果及类型化异常使用映射值。业务字段、规则编码、项目编码及外部供应商返回字段不参与替换。

SDK、HTTP/SDK runtime、服务端应同步升级后再启用映射。旧客户端严格校验标准码及固定描述，无法识别新映射。接口文档导出保留导出时的映射快照；配置变化后需重新导出。

MySQL、Redis、Kafka、项目加密主密钥、服务器证书及控制台登录启停等部署配置继续通过部署环境维护。
