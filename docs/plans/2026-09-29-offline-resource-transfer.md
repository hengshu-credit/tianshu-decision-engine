# 跨环境离线配置迁移

## 需求与验收边界

本计划来自本次用户要求，以实际实现和验证记录标记进度。离线迁移包在用户点击导出时生成，不在保存、编译或发布时提前生成。既有运行时决策制品仍承担冻结依赖和执行归因职责。

## 文件与依赖协议

- 复用现有 ZIP 摘要编解码器；使用独立 `packageKind=TIANSHU_RESOURCE_TRANSFER` 和 `resourceFormatVersion=1`，防止配置包误当运行制品部署。
- 资源由 `type:id` 包内键标识。源 ID 仅用于迁移映射，导入不能作为目标数据库 ID 使用。
- 配置快照复用治理聚合适配器，子字段/选项/实验分组随所属聚合一起导出。项目导出先选择项目自有与显式绑定资源，再递归上游依赖。
- 文件包含 PMML/ONNX 模型资产；外部 Java/Spring Bean 函数声明运行依赖，不能假装源环境类已经存在于目标环境。
- 项目调用 Token、登录账号、执行历史、账单、名单记录不属于配置包。连接/外数凭据与普通配置分开处理，界面明确哪些需在目标环境填写。
- 脚本动态引用无法由静态血缘保证完整；预览必须展示未解析项，不能按名称猜测并宣称闭包完整。

## 实施顺序

1. 资源包协议、类型目录、依赖引用与只读导出。
2. 目标项目映射、同码/同类型/同配置比较、逐项冲突预览。
3. 导入治理批次、ID/子字段/规则版本绑定重映射、事务和并发检查。
4. 各模块统一操作入口及完整向导。
5. 前后端测试、启动验证、两个独立环境完整导出→导入→执行回归。
