# 菜单切换等待复盘

## 历史证据与遗漏

- `cb86bfbe` 引入导航等待反馈；`ed2c28e3` 保留反馈并增加空闲串行预热、已验证会话异步复核；`52495d52` 延后规则测试/血缘图形库加载。相关优化并未被后续提交删除。
- 一级菜单仍是 Vue Router 异步路由。预热尚未完成或冷缓存时，路由必须等模块下载后才提交，旧页面上同时出现“正在打开”横条，并将内容向下挤动。
- 旧回归仅验证业务请求不挡住页面，却明确断言冷下载时保留旧页面并显示横条。把“已有即时反馈”当成“切换立即完成”，没有把用户的体验要求落实为冷缓存验收条件，这是此前修复不完整的原因。

- 登录、注册、账户恢复独立加载。详情、设计器、LogicFlow 画布与 Monaco 运行资源继续按需加载。共享入口仅加载代码，不挂载隐藏页面，不提前请求各模块业务数据。
