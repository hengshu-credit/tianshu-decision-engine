# 离线迁移项目合集

单项目 ZIP 可从控制台「离线迁移」导出。将已核对的单项目包固定为一个合集：

```bash
python3 scripts/package-project-set.py release.project-set.zip project-a.zip project-b.zip
```

单项目 ZIP 导入时，若勾选「导入并发布规则」，预检会显示所选规则随包携带的固定用例数。确认后先提交配置、规则草稿和固定用例，再针对导入的修订依次运行启用的用例，通过回归门禁后按正常审批发布。若中断，可在当前迁移页点击「继续验证发布」，从未完成的步骤接续。未勾选发布时只导入草稿。

在目标控制台选择 `.project-set.zip`，点击「预检项目合集」，核对项目编码、冲突及配置数量，再点击「导入项目合集」。各子包的源 ID 空间独立，导入时按实际目标 ID 建立关联。合集按源编码新建项目，保留全局依赖的作用范围。项目编码冲突须先处理。所有子包在同一数据库事务内导入；单项目绑定到已有项目仍使用普通配置包入口。

默认将规则保存为草稿。打包时添加 `--restore-published` 可让控制台预检列出源端已发布的规则和实验。勾选恢复发布再确认导入，控制台会按依赖顺序执行每个规则的启用用例，复核回归门禁，按正常审批发布，最后提交实验审批。此操作使用当前账号权限，测试可能产生真实的外数费用和名单动作。任一步失败即停止后续发布，页面会保留实际导入结果和失败位置。修复后可继续验证发布；同一账号重新预检同一合集时，可从成功迁移记录恢复绑定原目标 ID 的发布步骤。

未选择恢复发布时，引用随包规则草稿的实验也创建为待发布实验。先在「规则测试」按已保存的修订执行全部启用的固定用例，审批发布规则，再提交实验审批。线上执行使用目标环境的回归证据和发布制品。

项目鉴权迁移鉴权类型、非敏感参数、访问策略和状态。新项目在目标环境生成凭据。运行日志、审批操作历史和源环境密钥不进入合集。项目测试用例会携带操作者配置的输入和预期，导出前应核对其分发范围。默认不导出名单记录。有明确授权的演示记录时，打包参数 `--list-records 文件.json` 接受以项目编码为键的 JSON，每条记录必须指定子包内的 `libraryKey`、`itemType`、`itemContent` 和 `reason`。预检显示记录条数，只能写入本次新建的项目名单，写入经过名单变更校验、提交和审批。

部署管理员可以在所有 server 节点只读挂载 `/run/secrets/tianshu-transfer`。可用 `rule-engine.transfer.bindings-directory` 更换目录。每个绑定文件以单项目 ZIP 的 SHA256 命名，如 `<64位摘要>.json`，仅对完全一致的子包生效。目录应由部署管理员控制，文件仅允许运行身份读取。使用安装级绑定须有全局 `system:edit` 权限和目标资源原有业务权限。绑定值不放在浏览器选项或迁移日志中。

绑定文件以源资源键为第一层。数据库可指定 `host/port/jdbcUrl/username/password`，SFTP 可指定 `host/port/username/password/knownHosts`，外数数据源可指定 `baseUrl/authConfig`，接口可指定 `authApiConfig` 与包中声明的回调签名秘密路径。项目资源内以鉴权配置编码为键，可指定本安装生成的 `identifier/secret`。配置只在导入时读取；包内可选的 Java 扩展、模型扫描以及部署端的数据库、HTTP、SFTP 服务仍按已有机制准备。

合集包含一个先写入的 `project-set.json` 和依序命名的 `projects/1.zip` 等子包，各条目以 ZIP 的 STORED 模式存储。服务端校验预检清单摘要、每个子包摘要、包内组件与来源项目。当前最多 16 个项目，合集上限 512 MiB。控制台按 1 MiB 分块上传，预检和导入复用该文件。代理需允许 1 MiB 的请求体。模型原件仍按目标环境的扫描和内存配置处理。

预检会检查需要新写入模型的目标节点能否完成 ClamD 扫描。扫描器缺失或不可用时，项目列表会显示原因，恢复服务后可对同一文件重新预检。部署步骤见[模型与素材上传扫描](server-upload.md#模型与素材上传扫描)。

在同一控制台切换菜单或工作区页签时，上传、后台导入和后续回归发布会继续。返回「离线迁移」后，按钮下方显示进度和当前动作。点击动作可查看按时间顺序记录的执行日志。服务端保留临时文件和任务结果约一天，成功导入的项目及业务审计按原有策略保留。
