# 衡枢 KYC 离线样例

配置包为同目录的 `衡枢KYC-三项人脸规则.zip`。模型权重和函数脚本随本地样例包交付。部署打包时若此文件存在，会通过 SHA-256 校验后放入部署 ZIP 的同一目录。源代码单独检出时请从获得授权的样例分发位置取得该文件。

- 项目编码 `HENGSHU_KYC`，项目名称“衡枢KYC”。
- 3 个决策流分别为 `KYC_FACE_LANDMARKS`（五点定位与裁剪）、`KYC_FACE_LIVENESS`（RGB 被动活体检测）、`KYC_FACE_CONSISTENCY`（证件照与现场照一致性比对）。
- 随包提供 26 个项目变量、11 个 ONNX 模型和 11 个 QLExpress 函数。脚本源文件位于同目录的 `functions/`。
- ZIP SHA-256 为 `7ef5659681583e0007760d8d5b29a4712a1892d6e841cb7743251a6bc895a7b4`。
- 从“函数管理”编辑脚本，点“测试当前脚本”可运行未保存的修改。列表的“测试”运行生效版本。图像尺寸、对应点变换、采样覆盖率和 CHW 张量由引擎内置算子提供。

## 加载样例

使用含图像算子的引擎版本，确认 ONNX 运行环境和扫描器就绪。此样例的最大模型为 260,704,652 字节，需允许相应的单文件扫描长度。

在控制台打开“离线配置迁移”，选择 ZIP。首次导入勾选“导入时新建项目”，填写上述编码和名称。变量同码策略选“同编码同类型复用”，资源冲突策略选“复用相同配置”，预览后确认导入。三项规则按默认设置保存为草稿，需发布时走正常审批。再次预览时选择已有目标项目；遇到不兼容的模型、修订或草稿，先复核冲突，保留原资源。

测试输入使用获得授权的图像。该包不含实人身份记录、业务流水或已执行测试证据。

## 更新已有 KYC 项目

在“离线配置迁移”上传同目录的 `衡枢KYC-函数脚本升级.zip`，目标选择已有的 `HENGSHU_KYC`。这个小包只包含项目绑定与 11 个函数。首次从 Java 实现切换到脚本时，在预检中核对这 11 项同编码函数，选择覆盖已有配置。后续导入相同版本时选“复用相同配置”。

在“函数管理”点击“测试”会自动填入每个函数自己的示例。图像输入为合成色块。未知检测器示例用于验证拒绝分支，执行时应显示“不支持的人脸检测模型”。其他十项示例应执行成功。
