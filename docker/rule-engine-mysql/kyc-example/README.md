# 衡枢 KYC 离线样例

配置包为同目录的 `衡枢KYC-三项人脸规则.zip`。模型权重和原生扩展随本地样例包交付。部署打包时若此文件存在，会通过 SHA-256 校验后放入部署 ZIP 的同一目录。源代码单独检出时请从获得授权的样例分发位置取得该文件。

- 项目编码 `HENGSHU_KYC`，项目名称“衡枢KYC”。
- 3 个决策流分别为 `KYC_FACE_LANDMARKS`（五点定位与裁剪）、`KYC_FACE_LIVENESS`（RGB 被动活体检测）、`KYC_FACE_CONSISTENCY`（证件照与现场照一致性比对）。
- 随包提供 26 个项目变量、11 个 ONNX 模型和 11 个 Java 函数。三个实现类和辅助类共用一个 JAR。
- ZIP SHA-256 为 `dac328b23d76de7c0242707a10d2d13a881612a7517ba0b57b65b546ba44ec56`。
- 包内扩展路径为 `function-jars/63b4ff84359947f433483e63a531ed838a65e57abb574ec15bbd9ef0f0a8801c.jar`。部署时可命名为 `hengshu-kyc-functions.jar`。

## 加载样例

先按[原生函数扩展部署说明](../../../docs/offline-function-libraries.md)部署并校验 JAR，确认 ONNX 运行环境和扫描器就绪。此样例的最大模型为 260,704,652 字节，需允许相应的单文件扫描长度。

在控制台打开“离线配置迁移”，选择 ZIP。首次导入勾选“导入时新建项目”，填写上述编码和名称。变量同码策略选“同编码同类型复用”，资源冲突策略选“复用相同配置”，预览后确认导入。三项规则按默认设置保存为草稿，需发布时走正常审批。再次预览时选择已有目标项目；遇到不兼容的模型、修订或草稿，先复核冲突，保留原资源。

测试输入使用获得授权的图像。该包不含实人身份记录、业务流水或已执行测试证据。
